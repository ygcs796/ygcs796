## Projetos em destaque

### [Site de Jogos de IP](https://github.com/ygcs796/projeto_site_jogos_ip)
Site desenvolvido para catalogar e compartilhar os jogos criados na disciplina de Introdução à Programação do CIn-UFPE. Conta com página de detalhes para cada jogo, suporte a dark mode e um sistema de geração dinâmica de cards via JavaScript.  
`HTML` `CSS` `JavaScript`

---

### [Chaves: em busca da chave perdida](https://github.com/ygcs796/projeto_chaves_pi)
Jogo desenvolvido em C com a biblioteca Raylib como projeto da disciplina de Programação Imperativa. O game tem temática baseada no seriado Chaves, com fases, NPCs, efeitos sonoros e músicas.  
`C` `Raylib`

---

### [Dungeon Master — LAJE](https://github.com/ygcs796/dungeon-master-ps-laje)
Jogo de RPG desenvolvido com Godot Engine como projeto da dinâmica de grupo do processo seletivo da Liga Acadêmica de Jogos Eletrônicos do CIn-UFPE (LAJE). O projeto inclui sistema de combate, NPCs e caixas de diálogo.  
`GDScript` `Godot`

---

### [Robô Leitor de Cores — Introdução à Computação](https://github.com/ygcs796/projeto-IC-20251)
Carrinho autônomo desenvolvido na disciplina de Introdução à Computação. O robô utilizava um sensor de cor para ler as faces de um cubo mágico permutado e, com base na cor detectada, executava movimentos diferentes — para frente, para trás, para a esquerda ou para a direita — de forma completamente autônoma.  
`Sistemas Embarcados` `C++ Arduino`
